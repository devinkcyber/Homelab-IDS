Executive Summary

A multi-phase web server attack chain targeting an Ubuntu 24 server running DVWA (Damn Vulnerable Web Application). I progressed from initial reconnaissance through privilege escalation to root, demonstrating detection across both network (Security Onion/Zeek/Suricata) and endpoint (Sysmon for Linux, MDE) telemetry layers. This chain emphasizes the critical network vs endpoint detection gap — SQL injection is only visible at the network layer.

Key Insight: Network vs Endpoint Detection Gap

SQL injection payloads exist only in HTTP request parameters. Endpoint tools like Sysmon never see them. Without network telemetry (Zeek http.log, Suricata), this entire phase of the attack is invisible.
