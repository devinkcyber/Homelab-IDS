Active Directory Attack Chain Rules

Custom detection rules covering discovery and privilege escalation in the AD environment.

Rule 1: Guest Account SMB Share Access

High
MITRE: T1135 / T1039 - Discovery
Source: SecurityEvent
Frequency: 5 min
Lookback: 1 hour
Entities: Account, IP, Host
KQL 
SecurityEvent
| where EventID == 5145
| where SubjectUserName has "guest"
| where ShareName has "DevinStuff"
| project TimeGenerated, SubjectUserName, ShareName,
RelativeTargetName, AccessMask, IpAddress
| order by TimeGenerated asc

False Positives: None expected - Guest accessing shares is always suspicious

Rule 2: New Machine Account Created

Critical
MITRE: T1134.002 - Privilege Escalation
Source: SecurityEvent
Frequency: 5 min
Lookback: 1 hour
Entities: Account, Host
KQL 
SecurityEvent
| where EventID == 4741
| parse EventData with * '<Data Name="ObjectDN">' ObjectDN '</Data>' *
| parse EventData with * '<Data Name="SubjectUserName">' SubjectUserName '</Data>' *
| parse EventData with * '<Data Name="TargetUserName">' TargetUserName '</Data>' *
| project TimeGenerated, CreatedBy = SubjectUserName, NewComputer = TargetUserName

False Positives: Legitimate computer joins - correlate with IT tickets
